# ADR-0002: k3s as the Kubernetes distribution

**Status:** accepted · **Date:** 2026-10-21

## Context
A single host must run GitLab, Vault and a three-node cluster. Full kubeadm with etcd and add-ons is heavy.

## Decision
k3s (pinned version) with Traefik and ServiceLB disabled (installed separately via Helm with MetalLB),
secrets encryption at rest, API audit logging and `protect-kernel-defaults`.

## Consequences
- Conformant Kubernetes with a small footprint; skills transfer to EKS/AKS/GKE.
- Single control-plane node: no HA (accepted for a lab).
- Ingress and load balancing are explicit, versioned components instead of bundled defaults.
